# Serverless Portfolio

A serverless developer portfolio built with AWS, Python, and TypeScript.

## Goals

- Automatically showcase public GitHub repositories.
- Host a responsive portfolio website.
- Build Python serverless APIs with AWS Lambda.
- Store application data in Amazon DynamoDB.
- Define cloud infrastructure using AWS CDK.
- Automate testing and deployment with CI/CD.
